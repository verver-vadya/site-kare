# Каре — сайт салона стрижки и окрашивания

Тестовый проект: сайт вымышленного салона «Каре» (Москва, Малая Бронная) в тёплом стиле по мотивам Nine Zero One: первым экраном зал салона с неоновой вывеской на кирпичной стене, рукописные капители, штукатурка, терракота и зелёный бархат.

- Превью: https://verver-vadya.github.io/site-kare/ (после включения GitHub Pages)
- Стек: [Astro](https://astro.build), на выходе обычные HTML-страницы без лишнего JavaScript; сделан из [site-template](https://github.com/verver-vadya/site-template).
- Шрифты: Amatic SC и Manrope (OFL), лежат в `src/fonts/`.

## Что поменять под настоящий салон

Всё, что повторяется на нескольких страницах, лежит в `src/data/` — менять нужно только там:

| Что | Где |
| --- | --- |
| Название, адрес, телефон, часы, Telegram, адрес формы | `src/data/site.ts` |
| Услуги, цены по уровням, шаги, вопросы | `src/data/services.ts` (список услуг в записи собирается отсюда же) |
| Мастера, уровни, работы мастера | `src/data/masters.ts` |
| Работы в лукбуке | `src/data/works.ts` |
| Статьи журнала | `src/data/journal.ts` |
| Цвета, шрифты, отступы | переменные в начале `src/styles/global.css` |
| Фото | `public/assets/img/`, источники в `CREDITS.md`; новые фото делает `tools/photos.py` |
| Адрес сайта | `site` в `astro.config.mjs` и `public/robots.txt` |
| Политика конфиденциальности | `src/pages/privacy.astro`, всё в `[ЗАПОЛНИТЬ: …]` |

## Как устроена вывеска

Вывеска взята с картинки-образца `tools/neon/sign-ref.jpg`: сверху на ней вывеска горит, снизу выключена. Скрипт `tools/neon/photo.py` совмещает обе половины, вырезает выключенные стеклянные трубки с держателями и добавляет им тень (`public/assets/img/neon-glass.webp`), а из горящей половины забирает свет трубок и свечение на стене (`neon-light.webp`). Где лежит картинка и где идут провода, скрипт пишет в `src/data/neon-photo.ts`. Провода нарисованы линиями поверх фото.

Всё это лежит в SVG поверх фото: `viewBox` равен размеру кадра, а `preserveAspectRatio` повторяет `object-fit` и `object-position` фото, поэтому вывеска всегда висит на одном и том же месте стены. Для вертикальных экранов свой кадр (правая часть того же фото), место вывески задаётся в `src/components/Hero.astro`. Свет кладётся режимом `screen` (складывается с фото), тёплый свет на всю комнату — оранжевая заливка в режиме `overlay`, сильнее всего у вывески.

Когда фото зала загрузилось (`main.js` ставит класс `is-ready`), свет три раза коротко мигает и за пару секунд разгорается, вместе с ним теплеет комната (`@keyframes neon-start` в `global.css`, не больше трёх вспышек в секунду). В режиме без анимаций и без JavaScript вывеска сразу горит.

Чтобы поменять вывеску, положите новую картинку-образец того же вида и запустите `python3 tools/neon/photo.py` (нужны `opencv-python`, `numpy`, `scipy`).

## Запись

Сейчас на сайте своя форма: заявка уходит администратору через [Formspree](https://formspree.io) (вписать адрес формы в `formAction` в `src/data/site.ts` вместо `YOUR_FORM_ID`; пока его нет, форма честно пишет, что не подключена). Под выбором услуги и мастера форма показывает цену у этого мастера.

Для настоящего салона лучше подключить сервис онлайн-записи (DIKIDI или YClients): живое расписание мастеров, напоминания клиентам и журнал для администратора. Аккаунт регистрирует салон, на сайт вставляется их виджет на место формы (место отмечено комментарием в `src/pages/zapis.astro`).

## Запуск локально

```bash
npm install
npm run dev      # http://localhost:4321, страница обновляется сама
npm run build    # готовый сайт в папке dist
```

## Автопроверка

`npm run check` собирает сайт и проверяет все страницы из `dist`: битые ссылки и ссылки на `#`, кнопки без реакции на наведение и нажатие, форму, которая молчит при ошибке или отправляется дважды, меню, которое не закрывается, ошибки в консоли, мелкие зоны нажатия, наложения и горизонтальную прокрутку от 320 до 2560 px и при масштабе Windows 125 и 150 %, сломанную 404, заглушки и штампы в текстах. В каждом pull request проверка запускается сама (`.github/workflows/check.yml`), отчёт и скриншоты лежат в артефакте `screenshots`. Подробности: `.github/check/check.mjs` и `.github/CHECKLIST.md`.

## Публикация

Превью на GitHub Pages собирается при каждом пуше в `main` (`.github/workflows/pages.yml`): включить в Settings → Pages → Source: GitHub Actions. Для настоящего салона с российской аудиторией сайт публикуется на российском хостинге (Timeweb, Beget, Reg.ru): туда загружается содержимое папки `dist`.
